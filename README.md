## Run Locally

Clone the repository:

```bash
git clone https://github.com/AbelGebretinsae/MyPortfolio.git
cd MyPortfolio
```

Start a local server:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.

## Deployment

The site is deployed with Vercel. Updates pushed to the `main` branch are automatically deployed to the existing production site.
